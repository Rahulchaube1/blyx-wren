# Wren starter

Run named checks and skips, compare floating-point measurements, and report a TAP 13 stream and a process exit status for CI.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Wren** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
3
1
1
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/wren) · [View the release](https://github.com/Rahulchaube1/blyx-wren/releases/tag/v0.1.0)
